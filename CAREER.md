# Using this project toward ~12 LPA startup roles

## Reality check

| Claim | Truth |
|-------|--------|
| “This website alone will get me 12 LPA” | **Unlikely.** One marketing site is a **portfolio piece**, not a full hiring packet. |
| What 12 LPA usually means in India (startups) | Roughly mid-level: proven shipping, solid JS/TS, system thinking, often 1–3+ years or exceptional internships. |
| What this repo *can* do | Show **product craft + modern stack** in interviews and on GitHub. |

## Package for startups (checklist)

- [ ] **Deploy live** (Vercel) — dead GitHub-only links lose offers  
- [ ] **Lighthouse** mobile 90+ (perf, a11y, best practices) — screenshot in README  
- [ ] **README** tells impact story (this file + root README)  
- [ ] **2–3 other projects** — API, dashboard, open source PR, or internship work  
- [ ] **Resume** — one line per project with stack + outcome  
- [ ] **LinkedIn** — same story; pin the live demo  
- [ ] **Practice** — JS deep dive, React, one system-design lite for startups  

## Target roles that fit this project

- Frontend Engineer  
- Product Engineer  
- Full-stack (if you add a small API / CMS next)  

Less of a fit alone: pure backend, ML, iOS-only.

## How to push toward 12 LPA

1. **Ship this live** and track something (even Google Analytics: CTA clicks).  
2. **Add one hard feature** — e.g. lead form → email/Slack, or CMS for offers.  
3. **Write a 1-page case study** (problem → decisions → tradeoffs → metrics).  
4. **Apply broadly** — YC/well-funded startups + strong Series A/B product teams.  
5. **Interview loop** — DSA light/medium + take-home + culture.  

## Interview talking points from this codebase

- `src/lib/site.ts` — config as product surface  
- `use-reveal` + reduced motion — inclusive UX  
- Transformations slider — pointer capture, keyboard, ARIA  
- Nitro `vercel` preset — deploy thinking  
- Schema.org — growth/SEO partnership with marketing  

## Red flags to avoid

- Claiming “built for Google/Apple job” on a gym landing page  
- No live URL  
- Inflating “1,200 members” without business approval  
- Only UI screenshots, no code walkthrough  

---

**Bottom line:** Make this the *best* project on a **stronger overall profile**. The site is the demo; **you** are the hire.
